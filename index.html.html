เชื่อมต่อ Google Sheet

วาง URL ของ Google Apps Script Web App ที่ Deploy แล้ว
วิธี Deploy: เปิด Google Sheet → Extensions → Apps Script → วางโค้ดใน Code.gs → Deploy → New deployment → Web App → Execute as: Me → Access: Anyone → Copy URL

บันทึก URL แล้ว — คลิก "ภาพรวม" เพื่อโหลดข้อมูล
เพื่อให้ทุกเครื่องเชื่อมได้อัตโนมัติ
เปิดไฟล์ HTML ด้วย text editor → หาบรรทัด const EMBEDDED_API_URL = 'https://script.google.com/macros/s/AKfycbz0zvGMnjJuG8WMdYTOnwy418TEQyn49BfjLsc7Z8Bj__6LQlPYxKBF8749CXtXxflZ0Q/exec' → วาง URL ของท่านระหว่างเครื่องหมาย '' แล้วบันทึกไฟล์ใหม่ จากนั้น deploy ขึ้น GitHub Pages อีกครั้ง

สำคัญ — วิธีเปิดไฟล์ที่ถูกต้อง
ห้ามเปิดไฟล์ HTML โดยตรง (file://) เพราะเบราว์เซอร์จะบล็อก CORS
ต้องเปิดผ่าน Local Server วิธีใดวิธีหนึ่งดังนี้:
VS Code: ติดตั้ง extension "Live Server" → คลิกขวาที่ไฟล์ → Open with Live Server
Python: cd ไปที่โฟลเดอร์ไฟล์ → พิมพ์ใน Terminal:
python -m http.server 8080
แล้วเปิด http://localhost:8080/inclusive_education_songkhla.html
Node.js: npx serve . → เปิด http://localhost:3000
